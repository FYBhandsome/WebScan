# 一、先给你结论

**代码里的目标IP = 你自己手动填写的！**

```python
target_ip = "192.168.181.101"  # 这是你自己写的！
```

代码**不会自动获取目标IP**，必须**你指定攻击谁**。

# 二、那你怎么知道【填哪个IP】？

必须**先查看你局域网里有谁在线**，才能填写目标。

## 方法：Windows CMD 查看在线设备（必须会）

以**管理员身份**打开 CMD，输入：

```cmd
arp -a
```

你会看到类似这样的列表：

```
接口: 192.168.181.165 --- 0xb
  192.168.181.25       xx:xx:xx:xx:xx:xx     动态
  192.168.181.101      xx:xx:xx:xx:xx:xx     动态
  192.168.181.102      xx:xx:xx:xx:xx:xx     动态
```

这些 **192.168.181.xxx** 就是**在线设备**。

你**随便选一个**，填到代码里：

```python
target_ip = "192.168.181.101"
```

---

# 三、代码里的 MAC 地址是怎么获取的？

虽然**目标IP需要你手动填**，但**目标MAC是代码自动获取的**！

代码里这个函数：

```python
def get_mac(ip):
    try:
        arp_request = ARP(pdst=ip)
        broadcast = Ether(dst="ff:ff:ff:ff:ff:ff")
        packet = broadcast / arp_request
        result = srp(packet, timeout=2, verbose=0)[0]
        return result[0][1].hwsrc
```

它的工作原理（考研408考点）：

1. 发送 **ARP 广播**
2. 目标设备收到后，回复自己的 **MAC 地址**
3. 代码拿到 MAC，才能进行 ARP 欺骗

# 四、总结（最重要）

## 2. **目标MAC = 代码自动获取**（发送ARP请求）

## 3. **必须填写在线IP，否则代码崩溃**
