# Demo Presentation - 演示展示模块

本目录包含项目演示相关的文件。

## 📁 目录结构

```
demo_presentation/
├── app.js              # 演示应用JavaScript
├── dvwa_api.py         # DVWA API接口
├── dvwa_connector.py   # DVWA连接器
├── index.html          # 演示页面
└── styles.css          # 样式文件
```

## 📖 说明

本模块用于演示 WebScan AI Security Platform 的核心功能，包括：

- 漏洞扫描演示
- DVWA (Damn Vulnerable Web Application) 集成
- 实时扫描结果展示

## 🚀 使用方法

```bash
# 启动演示服务
python dvwa_api.py

# 访问演示页面
# 打开浏览器访问 index.html
```

## ⚠️ 注意事项

- 本模块仅供演示和学习使用
- DVWA 是故意设计的有漏洞应用，请勿部署到生产环境
- 演示环境应与生产环境完全隔离
