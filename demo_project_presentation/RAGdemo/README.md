# RAGdemo - RAG技术演示

本目录包含 RAG (Retrieval-Augmented Generation) 技术的演示代码。

## 📖 项目简介

RAGdemo 是一个简单的 RAG 技术演示项目，展示了如何使用检索增强生成技术来提升AI回答的准确性。

## 📁 目录结构

```
RAGdemo/
└── demo.py              # RAG演示脚本
```

## 🚀 快速开始

```bash
# 运行演示
python RAGdemo/demo.py
```
